# Teochew and Swatow documentary galleries

Retrieved 9 October 2026. These photographs document places and activities, not the language or ethnicity of people pictured. Each gallery is a complete selection. Captions distinguish wider county surroundings where applicable. The selections refer to Teochew and Swatow cities in Guangdong, rather than similarly named places elsewhere.

All assets are resized and converted to WebP. Source-file licenses apply independently of the code license. Metadata was retrieved from Wikimedia Commons imageinfo and each selected image was inspected in a contact sheet.
